# Sweep — RTX PRO 5000 Blackwell 72 GB, 2026-10-09 (engine decode matched to the forward)

One full sweep, run on `more-optimizations` on top of `a7728a8e`, with the working tree
uncommitted. It covers fourteen width gates, three engine probes, and the Strata
benchmark run through the engine. Each model ran as its own `cargo` process, with zend
stopped so the card was free. Since the 2026-10-06 sweep
(`sweep_rtx_pro_5000_72gb_2026-10-06.md`), this build carries:

- **Flash-Next prefill and decode work** from `a7728a8e` and the commits before it:
  the prefill K/V prestage, the int8 paged-prefill kernels, the draft walk re-laying
  the standing tier in place, and arena-index recycling.
- **The engine's speculative accept walk scored in one dispatch.** Each sequence's
  verify rows are sampled together, through hypothetical advances and a rewind. The
  rows are read in place from the wave's logits block. Before this, there was one
  `cat` and one sampler launch per position.
- **A partial-accept rollback resyncs only the landing chunk** of the decode slot
  buffer. Before this, it resynced the whole writer region.
- **The compaction gate holds per frontier pass.** A span-tenant pass needs at least
  `MIN_FREEABLE_ARENAS` holes. An emptied arena that has not yet been swept still
  counts as holding the KV top.
- **The device settles only when the scheduler is idle.** Settle waiters are queued
  and answered from the idle branch. A settle forgets the last forward's tier.
- **Hot→warm migration grows its pinned scratch only after its GPU staging is
  granted.**

These are single runs, so a gap under about 5% is noise. Every gate row validated,
for every session. No probe log has a `non-finite` layer or a `!!!!`.

The story gate passed on every probe, so K/V and the recurrent state are intact. Both
failures are on the VRAM-efficiency gate alone. That gate was set aside for this round
of work. It is not a standing cost, and it is a regression against this card's own
history:

| Probe | 2026-10-04 | 2026-10-06 | this sweep |
|---|---:|---:|---:|
| Qwen3.6-35B-A3B | 95% | 97% | 66% |
| Qwen3.8-Flash-Next | 97% | 95% | 78% |

Both drops fall on the two models that carry recurrent span tenants. Those models are
the ones the per-frontier-pass stall and the `MIN_FREEABLE_ARENAS` floor on span-tenant
passes reach. The 30B, with no span tenants, holds at 99%. Earlier today, after the
compaction-gate change, the Flash-Next probe read 79% and then 78%. Open.

Wall clock: 174, 168 and 182 s.

**Sweep result: FAIL.** All fourteen gates passed, and the Qwen3-30B probe passed. The
Qwen3.6 and Flash-Next probes failed on efficiency only.

so acceptance is not reproducible across runs. A three-run median moves with it.
