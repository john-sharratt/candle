# Width gate sweep and engine probes — RTX 3090 24 GB, 2026-10-05

One run of each width gate and all three engine probes on `5776799ac` (`npc-engine`
merged with `origin/main`). That build adds the live MoE dispatch and KV compaction
work of `moe_live_dispatch_rtx_3090_24gb_2026-10-04.md`, plus what main carried in:
the GPU penalty count table, the compaction stall gate, Medusa typical acceptance for
sampled verify, the Flash-Next C10 retune (K 1.35, V 1.9), and the plain Qwen3.6-35B
gate moving from `Int8Mode::Performance` to `Int8Mode::auto` (Precision on this card).
Partial sweep for this card: every gate except DeepSeek-V4-Flash (284B). Every row is
in `performance_rtx_3090_24gb_rows_2026-10-05.tsv` (193 rows). Single runs, so a gap
under ~5% is noise.

Gates 1–13 and the Qwen3-30B probe ran first. The other two probes stopped when the
system drive filled during the Qwen3.6-35B probe's checkpoint download. They were re-run
on the same commit after `cargo clean` freed the space.

**Result: SWEEP PASS.** All 13 gates pass with every session valid, and all three
engine probes pass all three of their gates.
