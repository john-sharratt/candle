# Sweep — RTX PRO 5000 Blackwell 72 GB, 2026-10-05 (live MoE dispatch, typical acceptance)

One full sweep — fourteen width gates and three engine probes, one `cargo` process
per model, card to itself — on `main` at `5776799a`. Since the kernel-size sweep
(`sweep_rtx_pro_5000_72gb_2026-10-04_kernel_size.md`) this build carries:

- live MoE dispatch: the routed path dispatches from a live expert table, worker
  blocks stream remote experts in the same launch, and the per-layer routing
  readback to the host is gone; the live launch picks its token-tile width from
  rows per expert;
- KV compaction that keeps up: cross-pool moves ordered by source region, a
  clipped pass followed up to four times, and the no-progress gate that skips a
  pass on a pool shape the last one could not improve;
- typical acceptance in speculative verify (sampled rows only — every gate here
  decodes at temperature zero, so it does not appear in these numbers);
- a `live_vocab` bound in the sampling kernel, so a checkpoint's padded logits
  columns never carry probability;
- the gate harness reading the tokenizer's id bound once (`b705689b`). Before it,
  the decode timer of every row paid ~0.3 s to rebuild the vocabulary map; an
  earlier run of this sweep on the build without it read 7–50% low on every
  fast row, and is not recorded.

Single runs, so a gap under ~5% is noise. Every gate row validated, every session.

Three groups, each consistent across its own rows:

- **Dense and hybrid-dense models are level** (−2% to +2.5%). None of the build's
  changes reaches their forward.
- **Qwen3.8-Flash-Next is faster** — +22.6% single-stream and +17.8% at ×16, with
  prefill up as well (×1 warm 2,473.7 → 3,274.3, ×16 3,273.9 → 3,841.4). Its
  experts stream on this card, so removing the per-layer routing readback is
  where the time goes.
- **The fully-resident MoE models are 6–8% slower**, and **DeepSeek-V4-Flash
  decode is 29–40% slower** at every width (×4 36.8 → 24.7, ×8 53.3 → 33.3),
  with its prefill up 6–7%. The 30B and 35B hold every expert in VRAM on this
  card, so the live path's fixed costs buy them nothing; DeepSeek runs the
  `latent_moe` engine and streams most of its experts. Both regressions arrived
  with the live-dispatch merge and are not yet attributed.

Engine probes against the kernel-size sweep: Qwen3-30B 100% → 99% efficiency,
Flash-Next 97% → 97% with uptake 91% → 95%. Flash-Next's clean C5×8 engine decode
reads 653.0 against 584.1 measured on 2026-10-04 before the merge (+11.8%).
